# 評価データと来歴

## 公開用の複製

元の実験資料を保持したまま公開用コピーを作りました。`provenance/export_manifest.json` に配布ファイル、元ファイルの論理名、整理前後のSHA-256、削除項目を記録しています。入力2ファイルは実験時と同一のバイト列です。

`gold.jsonl` は確定済みの数量・金額ペア、対象識別子、本文ブロック、文字位置、確認状態を保持し、AI下書き・自由記述メモ・作業セッション等を除きました。確認者名は一貫した `reviewer-1` に置き換えています。これは一人の確認であり、複数人の一致度を示す資料ではありません。出力6ファイルでは所要時間・呼出し回数・試行回数を除き、回答と識別情報・設定・検査結果を保持しています。

コード中の `relations` / `relationship` は論文の「数量・金額ペア」および「位置」の採点に対応します。名称の変更によるスキーマ改変はしていません。

## 原文位置と入力範囲

文字位置は `expanded-block-surface-v1` の本文に対する開始位置を含み終了位置を含まない範囲です。PythonのUnicode文字位置であり、UTF-8バイト数ではありません。`source_block_text` とそのSHA-256が基準です。入力の `candidate_fingerprint` は内容全体に結び付き、予測の同じ識別情報と照合されます。

評価ファイルは完全な本文ブロックを含みますが、モデルに送る入力は `visible_input` が作る前後25語または80語の本文・候補・位置情報です。完全なブロックや正解がモデルに送られたことを意味しません。

## 保存版の限界

対象資料はDDbDPの142文書です。全150対象の配布本文をローカルXMLから再構成し、一致を確認しています。取得時のidp.data全体のコミットは確定していないため、推測値を記載していません。公開した本文ブロックとXMLのハッシュで、使用版の照合ができます。

全件適用は集計のみを配布します。29対象で出力を取得できず、9,193対象が検査を通過しました。検査を通過してペアのない7,328対象と、出力取得に失敗した対象を区別します。2,080ペアを2,073群へ整理した結果には7群の解釈の違いがあり、人手未確認です。

モデル名は実験に保存されたIDをそのまま収録します。現在同じモデルを利用できることや、新しい呼出しが同じ結果を返すことは保証しません。実行環境の依存関係と公開コードは、公開時の固定ファイルとして配布しています。
